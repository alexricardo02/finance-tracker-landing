3. Recopilación de datos en la aplicación Finance Tracker 3. Datenerfassung in der Finance Tracker App

Finance Tracker es un proyecto de software para el portafolio. Cuando utiliza la aplicación y se registra, procesamos los datos como parte de la prestación del servicio: Finance Tracker ist ein Portfolio-Softwareprojekt. Wenn Sie die App nutzen und sich registrieren, verarbeiten wir Daten im Rahmen der Bereitstellung des Dienstes:

  • Datos de la cuenta: Dirección de correo electrónico y contraseña. Las contraseñas se encriptan mediante BCrypt y nunca se almacenan en texto plano. Account-Daten: E-Mail-Adresse und Passwort. Passwörter werden mittels BCrypt kryptografisch gehasht und niemals im Klartext gespeichert.
  • Datos financieros: Ingresos, gastos y categorías. Estos se procesan en nuestra base de datos PostgreSQL (alojada en Neon). Finanzdaten: Eingegebene Einnahmen, Ausgaben und Kategorien. Diese werden in unserer PostgreSQL-Datenbank (gehostet bei Neon) verarbeitet.
  • Autenticación: Para un inicio de sesión seguro, utilizamos JSON Web Tokens (JWT) y Redis (Upstash) para caché, sesiones y Rate-Limiting para proteger contra ataques. Authentifizierung: Für den sicheren Login verwenden wir JSON Web Tokens (JWT) und Redis (Upstash) für das Cache- & Session-Management sowie Rate-Limiting zum Schutz vor Angriffen.
  • Backend: La API REST se proporciona utilizando Spring Boot y está alojada en Render. Backend: Die REST-API wird mittels Spring Boot bereitgestellt und auf Render gehostet.

Sus datos se tratarán de forma estrictamente confidencial, no se utilizarán con fines publicitarios y no se venderán a terceros. El procesamiento se basa en el Art. 6 Párrafo 1 letra b del RGPD (Cumplimiento del contrato). Ihre Daten werden streng vertraulich behandelt, nicht für Werbezwecke verwendet und nicht an unbeteiligte Dritte verkauft. Die Verarbeitung erfolgt auf Grundlage von Art. 6 Abs. 1 lit. b DSGVO (Vertragserfüllung).
